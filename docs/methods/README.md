# Method registry

Every scientific or heuristic method gets one document containing:

- identifier, name, version and status;
- purpose and claim type;
- mathematical definition and units;
- assumptions and applicability bounds;
- parameters and defaults;
- primary sources where applicable;
- synthetic and real-data validation;
- known biases, failure modes and alternatives;
- uncertainty method and confidence-index rubric mapping;
- affected requirements and tests.

Allowed statuses: Established, Project-validated, Experimental, Heuristic,
Presentation-only and Rejected. Internet popularity is not evidence status.
